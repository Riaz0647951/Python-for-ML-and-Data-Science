## ⚠️ Important Note About Dataset File Paths

When you download the coding files and datasets from this repository, **you may need to change the dataset file paths in the coding files to match the location of the datasets on your own computer.**

The original file paths used in the notebooks may refer to directories on my local computer and may not work on your system.

For example, if a notebook contains:

```python
import pandas as pd

df = pd.read_csv("C:/Users/YourName/Desktop/Numpy/datasets/data.csv")
```

You should update the file path to the actual location of the dataset on your computer.

For example:

```python
import pandas as pd

df = pd.read_csv("datasets/data.csv")
```

The second example works when the dataset is located inside a `datasets` folder relative to the notebook's working directory.

**Please verify the dataset location and update the file paths accordingly before executing the coding files.**
